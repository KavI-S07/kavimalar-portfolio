# S Kavimalar — Developer Portfolio

A minimal white-and-lavender personal portfolio built with React and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Update project descriptions and technology stacks in `src/main.jsx`.
- Add repository links to project cards when your public repositories are ready.
- Add a professional email address in the Contact section when you want it displayed.
- Replace the initials illustration in the hero section with a profile photo if desired.

## Tech stack

React, Vite, CSS, Lucide React.
